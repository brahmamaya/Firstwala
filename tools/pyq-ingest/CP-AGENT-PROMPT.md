# Prompt for a text-first NEET agent (Career Point "Paper & Solution" PDFs with a text layer)

`careerpoint-prep.js` already copied the questions, options, printed keys and the publisher's solution out of the PDF text layer into `<paper folder>/batches/b-NN.md`. You work ONLY on the batch file named in your task, `tools/pyq-ingest/neet-chapters.json`, and (only when a question says `[OPEN PAGE IMAGE: ...]`) the page image `<paper folder>/pages/pNNN.jpg` (110 dpi, NNN = the PDF page number shown in the question header). Do not scan the repo.

For every question write ONE JSON line, appended to `<paper folder>/entries-NN.jsonl` right after you finish that question (so nothing is lost if you are interrupted):
`{"pn":<n>,"sub":"Physics|Chemistry|Botany|Zoology","ch":"<chapter EXACTLY as in neet-chapters.json for that subject>","st":"<NCERT sub-topic, 2-5 words, same wording for the same idea>","q":"<question>","o":["<1>","<2>","<3>","<4>"],"c":<0-based index>,"s":"<solution>"}`

Rules (accuracy first; never guess):
1. `q` and `o`: take the words from the batch text (they are exact). The text layer loses maths structure: write fractions as (a)/(b), roots as √, powers and indices as unicode (x², 10⁻⁵, H₂SO₄, Fe³⁺, SO₄²⁻, vₓ), Greek letters, ×, ÷, ≈, →, ⇌ exactly as printed. When a question is marked `[OPEN PAGE IMAGE: maths]` look at the page image and write the maths from the image. Chemical formulas and charges must be exact. Do not change a word.
2. `c` = printed `Ans. [k]` minus 1. If the key is not a plain 1-4 (for example `2 or 3`, `Bonus`, `*`), write `"c":null,"a":"<exactly what is printed>"` and `"flag":"<one line>"`. If your own working disagrees with the printed key, keep the PRINTED key and add `"flag":"printed answer k; my working gives X because ..."`. Never change a key silently.
3. `s` = the publisher's solution rewritten in YOUR OWN words (never copy sentences), one idea per line separated by `\n`, short sentences for ages 15-18, but keep EVERY step, formula, number and reason. No new facts. If the printed solution is only a word or a line, keep it that short. If the solution is missing or is only a picture (`[OPEN PAGE IMAGE: solution is thin]`) read the image; if there is truly none, write a short correct solution and add `"flag":"The paper prints no solution; this working is added here."`.
4. Pictures: if the question (or its solution) contains a picture (graph, circuit, ray diagram, structure, biological figure, a table drawn as an image) do not draw it. Add `"dia":"<precise description: every label, value, direction, axis, position, so it can be redrawn exactly>"` for the question picture and `"sdia"` for a solution picture. If the options are drawings, write the options as "(1)" to "(4)" in `o` and describe each in `dia`. Open the page image whenever the header says `[OPEN PAGE IMAGE: picture?]` or the options look empty or cut.
5. `sub` / `ch`: by content (the printed subject headings may be missing in older papers). Biology: plant, microbe, ecology, cell, biomolecules, genetics and biotechnology topics -> Botany; animal and human topics -> Zoology (the chapter must exist in that subject's list; if none fits use the nearest chapter of the OTHER biology subject and set `sub` to it).
6. Never write the publisher's name, logo, website, address or phone, or "Students may find similar question..." lines, anywhere in an entry.
7. A garbled or unreadable part: do not invent it. Write `{"pn":<n>,"gap":"what is missing"}` instead of the entry.
Final report (3 lines max): number of lines written, pn with `dia`/`sdia`, pn with a `flag` or `gap`.
