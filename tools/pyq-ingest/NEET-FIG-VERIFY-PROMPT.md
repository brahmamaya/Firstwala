# Prompt for a NEET diagram VERIFIER (blind check of redrawn figures against the printed pages)

You check diagrams that another agent redrew as `PhysicaFig` specs. You do NOT edit any figure file. Work ONLY on the figs file and pn list named below. Open: the figs JSON, the printed page images (`content/pyq-work/neet2026/pages/pNN.jpg`), and the entry line of each pn in `content/pyq-work/neet2026/entries-NN.jsonl` (grep). Render the figures with
`NODE_PATH=/tmp/nm CHROMIUM=/opt/pw-browsers/chromium node tools/pyq-ingest/fig-sheet.js <figs.json> /tmp/verify-<ID>.png <pn,pn,...>` and Read the PNG (render a few pn at a time if it is too small to read).
For every figure, compare it with the printed picture and list EVERY mismatch: a missing, extra, wrong or clipped label/value/unit/subscript, a wrong direction or arrow, a wrong connection (circuit topology, bond, position of a point), a wrong curve shape/trend or intercept, options (1)-(4) swapped or mislabelled, overlap that hides something, text outside the box. Also check that the figure matches the question text and options in the entry. Be strict: the owner needs exact accuracy. Do not suggest cosmetic changes.
Write the result to `content/pyq-work/neet2026/verify-<ID>.md`: one line per pn+figure: `OK` or `FIX: <what is wrong and what the page shows>`. Final report (3 lines max): counts of OK and FIX, and the pn numbers needing a fix.
