Images in two inclined mirrors

Place an object between two plane mirrors and change the angle. Count the images.

Open the simulation

What to notice

Each image can act as an object for the other mirror until the image falls behind both.

Key relation

n = 360°/θ − 1 (when 360°/θ is even)

Try this

Set θ = 60°, then 72° with the object off the bisector.

What you can change

  • Angle between mirrors θ: 30 to 180 °
  • Object position (fraction of θ): 0.1 to 0.9
