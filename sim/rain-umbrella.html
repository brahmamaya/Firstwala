Rain and the tilted umbrella

Walk through vertical rain and find the umbrella tilt that keeps you dry using relative velocity.

Open the simulation

What to notice

In the walker’s frame the rain slants toward them, so the umbrella must lean forward.

Key relation

v_rain,you = v_rain − v_you ; tan θ = v_you / v_rain

Try this

Walk faster with the same rain speed. How does θ change?

What you can change

  • Walking speed: 0 to 8 m/s
