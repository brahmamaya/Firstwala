Dimensional analysis of a pendulum

Test which quantities can set a pendulum’s period by matching dimensions on both sides.

Open the simulation

What to notice

Changing the bob’s mass leaves the period unchanged — exactly as dimensional analysis predicts.

Key relation

T = k L^a g^b m^c → a = ½, b = −½, c = 0

Try this

Make the bob five times heavier. Then quadruple the length instead.

What you can change

  • String length L: 0.2 to 3 m
  • Gravitational field g: 1.6 to 25 m/s²
  • Bob mass m: 0.1 to 5 kg
