PHYSICA - NETLIFY-READY STATIC WEBSITE

DEPLOY
1. Extract this ZIP. index.html must be directly inside the extracted folder.
2. Open Netlify Drop (https://app.netlify.com/drop) and sign in if requested.
3. Drag the extracted folder containing index.html into Netlify.
No build command, backend, database, API keys, or environment variables are needed.
The ZIP itself can also be used by deployment tools that accept ZIP archives.

INCLUDED

BUILD: index.html loads physica-core.min.js (sync) and physica.min.js (defer); physica-3d.min.js (detailed
3D scenes + Ultra scenes) is fetched after the page is up (lazy.js), and sw.js caches files for instant repeat visits.
from the readable source files by: node tools/build.js  (needs esbuild). Edit the sources, then rebuild.
ULTRA SCENES: ultra3d.js holds hand-built Ultra-Realistic scenes (window.PhysicaUltraScenes[id]); first: gravity-depth.
MATH: mathtext.js shows _ and ^ as real subscripts/superscripts on the page and in canvas drawings.
FOCUS: less important panels are compact and have a close (x) button; hidden ones return from the

TEACHER (tutor-teacher-content.js): offline adaptive teacher - replies in English, Hinglish or Hindi (follows the student),
asks the student's level (basic / average / JEE-NEET) and explains at that level, notices confusion / boredom / happiness,
answers follow-up questions with analogies and examples, and gives practice problems with hints. Pilot chapter: Motion in a Plane.
TUTOR: Normal / Student / Teacher modes, chosen as step 3 on the landing page (tutor.js). Normal: unchanged. Teacher: projector view.
Student: an "AI Tutor" switch in the top bar turns the tutor on. It covers every physics chapter (tutor-chapters.js) plus automatic
"what does this control do" answers and demos built from each simulation. Chat (tutor-speech.js + tutor.js): a conversation with typing bubbles; the tutor asks back (predict first, quick checks);
numbers in a question are calculated with the simulation ("what if angle is 60"), "increase/double X" is worked out, other
questions are matched across all chapters with "did you mean"; female voice, physics read naturally. Ask by typing or voice, answers read aloud, Predict → Show me demos, spoken quiz (browser speech; no AI service).
LANDING: the site opens on "Welcome to Physica" where the visitor picks class and mode, then Physics opens at the
first chapter (Class 11: Units and Measurements); subjects are switched inside the lab (landing.js);
shared links (#sim-id) skip it, and the logo brings it back.
VIEWS: every simulation has three views - 2D (clean flat diagram or hands-on), 3D (rotate/zoom)
and Ultra-Realistic (photographic workbench, warm lighting, bloom, vignette and film grain).

SHARING AND STORAGE
Save stores up to 30 worlds in your current browser, not in a cloud account.
Share / Export creates a snapshot link or a .physica.json file.
Friends open a link or use Import file. Imported worlds open paused for editing.
Create share links on your published Netlify domain, not the preview domain.
Large worlds should be sent as files. JSON world files are limited to 250 KB.
Browser data is separate for each domain. Export any preview saves before moving
sites. An exported file is the safest backup. Clearing browser storage removes
local favourites and saves.

SANDBOX MODEL
100 world pixels = 1 metre; fixed 10 m by 6.5 m world, up to 150 objects and
200 connections. Springs use solver stiffness, rods keep a fixed distance.
Charge/attractor forces are illustrative, not calibrated electromagnetism.
Speed is limited to approximately 24 m/s for numerical stability; high-speed
collisions are approximate. Objects without boundaries stop beyond 50 m.
All scene changes can be undone (last 50 edits); continuous playback is not
recorded by undo. Reset run restores the start of the latest Play session.
Use Pause for precise placement, then select an object to edit its properties.

TECHNICAL
Plain HTML, CSS and JavaScript. physica3d.js is a small built-in 3D renderer
(perspective, depth sorting, lighting, orbit camera) with no external libraries;
labkit.js and seventh.js to tenth.js hold the 100 newer 3D physics experiments;
phys3d-a.js to phys3d-d.js give the 176 original physics experiments their 3D scenes
(instruments2d.js: hands-on vernier caliper and screw gauge with drag, contact and magnifier);
(optics2d.js: hands-on Ray Optics, 12 sims: drag candle, laser, coin, prism, lenses, eyepiece on a real optical bench);
biokit.js and bio1.js to bio5.js hold the 100 biology experiments.
Matter.js 0.20.0 and its MIT licence are included
locally in vendor/. No external scripts or CDN dependency. No React build is
needed for this archive. Use a current Chrome, Safari, Firefox or Edge browser.
