# Zoology / human physiology / genetics simulation audit

Scope: Biology simulations in `bio1.js` to `bio5.js` that are zoology, human physiology, genetics, molecular basis of inheritance, evolution, biotechnology, and human health and disease. Botany, plant physiology, cell biology, cell cycle and biomolecules belong to the other audit.

## How this audit was done (read this first)

- Method: static reading of the code (draw functions, metrics, data tables, helper functions in `biokit.js`) with arithmetic on the coordinates. Biology facts were checked against my own knowledge of NCERT-level biology. I did not have the textbook open, so no row cites a page or table number. Anything I could not settle is marked FLAG FOR REVIEW.
- Nothing was rendered. No Chromium is installed here (`tools/e2e/shot.js` expects `/opt/pw-browsers/chromium`). Every "overlap", "position" or "overflow" finding comes from reading the coordinates and has not been seen on screen. The status column says so where it matters.
- `docs/simulation-quality-audit.md` (the inventory named in the task) does not exist in this worktree or in git history. The scope was taken from the `chapter` and `group` fields in the code instead.
- No `.js` file was changed.
