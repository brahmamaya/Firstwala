# Rank-mode chapter: set-up and agent prompts (paste, fill the <...> parts)

## Set-up per chapter (do first, in this order; it is a few edits)
1. `rank-neet.js`: add the chapter to `CHAPS` (`{d:'PhysicaRank<X>Jee', mock:'<bank name>', k:'-<x>', s:'maths'}`; Physics chapters need no `s`; add `nomock:true` if there is no bank; add `q:'PhysicaRankPyq<X>'` only when the PYQ file exists). Maths chapters are already listed in `JEE_MATH` (names as printed in the book, no extra words).
2. `tools/build.js`: add the data file to `CH_LAZY` (lazy bundle `physica-ch-*.min.js`, loaded when the chapter opens).
3. Create a stub `rank-<x>-jee.js` (`window.PhysicaRank<X>Jee={chapter:'...',secs:[],table:[],formulas:[],look:[],notes:[],asked:[],guide:{intro:'',plan:[],basics:[],path:[],think:[],watch:[],myths:[]},extra:[]}`).
4. Mock bank: Maths banks go in `tutor-exam-math.js` (`Object.assign(window.PhysicaMockBank,{...})`, same bundle as tutor-exam.js). Physics banks are in tutor-exam.js.
5. Figures: new chapters draw their figures INSIDE their own lazy file with `PhysicaRankFigKit` (`const {hs,ht,hl,hv,dot,arcp,dsh,dim,pth,cp,mk,fin,INK,DIM,HI,BLUE,GRN,RED}=window.PhysicaRankFigKit; function name(){...} PhysicaRankFigKit.add({name,...})`), so the main Rank bundle does not grow. (Older chapters keep theirs in the `FIGS` blocks of rank-figs.js.)
6. Spawn at most 2 agents at a time, `model: "sonnet"`, NO worktree (they work in the shared checkout on different files; a worktree starts from main and misses the set-up). They never commit; you run `node tools/ship.js check --e2e`, `commit`, `sync`, PR, merge, `after-merge`.
