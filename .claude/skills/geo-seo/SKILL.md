# GEO / AI-search visibility
What helps (and is honest): clear, factual, self-contained pages that answer one question; a short answer first, then detail; visible facts that match the structured data; crawlable plain HTML (the `/sim/*.html` and `jee-main-*.html` pages already are); `llms.txt` at the root (generated by `tools/seo.js`: what Physica is, hubs, chapter pages, citation notes); `robots.txt` that allows crawlers (it does, `Allow: /`).
How: put the key relation, "what to observe" and "try this" near the top of each page; FAQPage JSON-LD only for questions that are really answered on the page; keep chapter names and class labels consistent everywhere; mention the source of every claim in the page itself.
Not possible or not promised: guaranteed citations, injecting text for crawlers that users cannot see (hidden text is penalised), measuring AI traffic without analytics support. Check manually by asking an assistant a few real student questions and noting whether physica.in is cited; report it as an observation.
